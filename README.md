# Koko & Co. Storefront

Live storefront for Ghanaian porridges.

## Public site

https://kwesimk102.github.io/koko-and-co-storefront/

The site is deployed from `index.html` by the GitHub Actions workflow in
`.github/workflows/pages.yml`. Push changes to `main` to publish an update.

The browser app connects directly to Supabase using its public publishable key.
Never put a Supabase secret or `service_role` key in this repository.
